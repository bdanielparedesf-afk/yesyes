授权 Authorization/auth/token/create 功能描述： 本API用于获取 Access Token。开放网关基于标准的 OAuth 2.0 协议完成授权流程，该接口对应授权流程中获取 Access Token 的核心环节。 使用场景： 在调用开放平台 Open API 之前，必须先通过此API完成卖家（Seller）对应用（APP）的授权。完整的授权流程请参考：授权流程。 该API返回的 Access Token 是后续调用所有 Open API 的授权凭证，请务善保存并在请求中携带。 注意：参数 uuid 为选填项。若传入该参数，请确保在生成授权码（code）与获取令牌（token）时，传入的值保持完全一致 Feature Description: This API is used to obtain an Access Token. The Open Gateway is built upon the standard OAuth 2.0 protocol to complete the authorization process, and this API serves as the core step for acquiring the Access Token. Use Case: Before calling any Open APIs, you must use this API to complete the authorization from the Seller to the App. For the complete authorization process, please refer to: [Authorization Process]. The Access Token returned by this API serves as the authorization credential for all subsequent Open API calls. Please store it securely and include it in your requests. Note:The uuid parameter is optional. If provided, please ensure that the value remains exactly the same when generating the authorization code and when requesting the token.
/auth/token/refresh 功能描述： 本API用于刷新 Refresh Token。入参需传入 /auth/token/create 接口返回的 Refresh Token。开放网关基于标准的 OAuth 2.0 协议，当 Access Token 过期时，可通过本API获取新的 Access Token。 使用场景： 当 Access Token 过期或即将过期时，通过本API静默获取新的 Access Token，以延长会话的有效时长。 注意： Refresh Token 本身具有独立的有效期限制，若 Refresh Token 也已过期，则需重新进行完整的授权流程。 Feature Description: This API is used to refresh a Refresh Token. The request parameter requires the Refresh Token returned by the /auth/token/create endpoint. Built upon the standard OAuth 2.0 protocol, the Open Gateway utilizes this API to issue a new Access Token when the current one expires. Use Case: When an Access Token has expired or is about to expire, this API can be called to silently obtain a new Access Token, thereby extending the active session duration. Note: The Refresh Token has its own independent expiration limit. If the Refresh Token has also expired, you must re-initiate the complete authorization process.
商家 Seller global.seller.channel.info.get 功能描述：用于查询卖家（Seller）在不同类型店铺下的渠道卖家ID（channel_seller_id），单店模式下，channel_seller_id与seller_id是一样的。 使用场景：在AE平台中，同一卖家（Seller）可能支持多渠道（如Local、AliExpressDirect）运营，每个渠道对应独立的渠道卖家ID（channel_seller_id），且商品与订单均与该ID绑定。因此，在查询商品或订单时必须携带该参数。 本API用于获取 channel_seller_id 列表。 特别注意：若返回结果中不包含 channel_seller_id，说明当前为单店模式，直接使用 seller_id 即可。 Feature Description: Queries the Channel Seller ID (channel_seller_id) for a seller across different store types. In single-store mode, the channel_seller_id is identical to the seller_id. Use Case: On the AliExpress (AE) platform, a single seller may operate across multiple channels (e.g., Local, AliExpressDirect). Each channel corresponds to a unique channel_seller_id, and all products and orders are bound to this ID. Therefore, this parameter must be included when querying products or orders. This API is designed to retrieve the list of channel_seller_ids. Note: If the API response does not contain a channel_seller_id, it indicates that the account is in single-store mode. In this case, please use the seller_id directly.
